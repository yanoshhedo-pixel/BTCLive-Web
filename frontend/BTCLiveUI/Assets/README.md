# Alert Sound Instructions

Place your custom alert sound file here named `alert.wav`

## Requirements
- Format: WAV (Waveform Audio File Format)
- Recommended duration: 0.5 - 2 seconds
- Recommended sample rate: 44.1 kHz
- Recommended bit depth: 16-bit

## Default Behavior
If no custom `alert.wav` file is provided, the application will use a system beep as fallback.

## Finding Alert Sounds
You can find free alert sounds at:
- https://freesound.org
- https://mixkit.co/free-sound-effects/
- https://www.zapsplat.com

## Example Sounds
Good options include:
- Short beep/ping sounds
- Bell/chime sounds
- Notification tones

Make sure the sound is not too loud or too long to avoid disruption during active trading.
